# Data Directory

This directory contains the dataset used for the project.

- `raw/`: Place the raw dataset files here (e.g., `elliptic_txs_features.csv`, `elliptic_txs_edgelist.csv`, `elliptic_txs_classes.csv`). See `DATASET_SETUP.md` at the project root for instructions.
- `processed/`: The preprocessing pipeline (`src/data/preprocessing.py`) will output cleaned and merged datasets here.

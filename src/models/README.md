# Models Directory

This directory is reserved for Phase 2.
Here we will implement various PyTorch and PyTorch Geometric models, such as:

- `gcn.py` (Graph Convolutional Network)
- `sage.py` (GraphSAGE)
- `gat.py` (Graph Attention Network)
- `baselines.py` (Random Forest, XGBoost wrappers for comparison)
